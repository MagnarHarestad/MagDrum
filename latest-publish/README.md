# MagDrum local test packages

Public release [v0.1.1-test.141](https://github.com/MagnarHarestad/MagDrum/releases/tag/v0.1.1-test.141) contains Windows x64, Windows ARM64 and Linux x64. The Windows VST scan now includes Cubase 15 Media folders; regression coverage verifies the configured roots and duplicate removal. The Windows UI avoids non-ASCII punctuation in the sample-sort label and scan summary to prevent code-page glyph corruption; all eight language choices remain available. The Linux archive includes a per-user installer for the app and VST3; its update test confirms old bundles are backed up outside plug-in scan paths. Windows x64 and Linux Release CTest suites passed (2/2 each). Windows ARM64 app, VST3 and helper were cross-compiled; all three PE headers identify ARM64. ARM64 runtime testing remains outstanding. Linux CTest loaded the byte-identical release module through JUCE's VST3 host, scanned MIDI notes 0–127 and verified audible note 36 after restoring saved state. Ardour 8.4 scanner also recognized the package in Ubuntu 24.04 WSL2. An interactive Ardour session and physical Linux audio-device test remain outstanding.

The system-installed Windows VST3 remains .135. The installer refuses replacement while Cubase15.exe is running, including when it has no visible window. After that process exits, run the bundled `Install-MagDrum.ps1 -AllUsers` script as administrator. It installs into `C:\Program Files\Common Files\VST3\MagDrum.vst3` and moves the previous bundle to `%ProgramData%\MagDrum\VST3-backups`. Restart Cubase and rescan its VST3 plug-ins to use the new build.
