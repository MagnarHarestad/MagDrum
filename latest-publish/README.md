# Latest MagDrum packages

Download the current Windows x64 test package from [MagDrum v0.1.1-test.11](https://github.com/MagnarHarestad/MagDrum/releases/tag/v0.1.1-test.11).

The current package is:

- `MagDrum-Windows-x64.zip` — standalone app, VST3 and PowerShell installer.

The package is intended for testing the VST3 instrument in Cubase Pro 15. The standalone sequencer supports meter-aware bars and per-step MIDI velocity. Its SHA-256 is `874450c7b87da526c182816b89fcbfeffed2a42058e8a0b62fc5fd06a64fcb3e`.

Windows ARM64, separate Intel and Apple Silicon macOS, and Linux x64 archive jobs are configured in GitHub Actions but cannot run while account billing blocks Actions. Those archives are not yet available. See [installing.md](../docs/installing.md) for host setup instructions.

Archives generated locally are ignored here; this directory is the in-repository package index.
