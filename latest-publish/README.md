# Latest MagDrum packages

The local Windows x64 package is `MagDrum-Windows-x64.zip`. It contains the standalone app, VST3 instrument, and PowerShell installer for Cubase Pro 15 testing. It is published as [MagDrum v0.1.1-test.67](https://github.com/MagnarHarestad/MagDrum/releases/tag/v0.1.1-test.67), a locally built release that does not use GitHub Actions. Its SHA-256 is `a1c542ba4aa8f95935539b775b3fe90845b1d66cf71cd225b54c4226d32be301`.

The desktop sample browser uses debounced background SQLite searches and fetches matching results in 250-sample pages, including text/tag, category, source/kit, feature, review, and sort filters. Sample scans persist each analyzed file immediately; plugin scans persist each completed capture so both can recover after interruption. Classifier-generated tags are stored separately from user tags, searchable, and shown in sample rows. Bright and Dark tags use spectral centroid, Short is based on duration regardless of loudness, common distortion filename forms map to Distorted, and standard BD/SD/CHH/OHH/PHH abbreviations map to drum categories. Analysis version 5 added spectral flatness; version 6 adds transient attack count; version 7 recognizes common SFZ family codes and reclassifies existing libraries once while preserving user tags and category corrections. Noise-like transient fixture WAVs are classified as Closed/Open hi-hats by measured flatness and duration; tonal percussion remains a Snare. A generated pitched tom WAV is scanned and classified by its measured pitch, centroid, duration and transient, with low confidence for review. A four-pulse WAV exercises low-confidence Clap classification from measured transient count, brightness, flatness, duration and transient ratio. Filename-based articulation labels are searchable heuristics, not waveform recognition. The plugin scanner offers offline-fast, realtime-paced, and system audio-device callback modes. It scans only the requested velocity levels. The VST3 sampler supports up to eight non-overlapping velocity layers per MIDI note. App and VST3 product metadata now match version 0.1.1. The installer warns about a pre-existing system-wide VST3 to help avoid duplicate Cubase entries. MIDI export can optionally apply articulation fallback and reports every substitution and omitted event. Both CTest suites passed (2/2), including 250,000-row paginated browsing with index-backed name ordering, worker-crash recovery, an isolated end-to-end scan of the built VST3 with restored sample state and audible note-36 capture, realtime pacing, sample-rate metadata, virtual callback rendering, VST3 velocity-layer state checks, filename-boundary and SFZ family classifier checks, classifier-tag persistence/search/reclassification, articulation-tag search, and generated WAV spectral-flatness, tom, and Clap classification/persistence fixtures. Third-party plugin behavior and the mobile preview's iOS runtime remain unverified. The new local archive SHA-256 is `a1c542ba4aa8f95935539b775b3fe90845b1d66cf71cd225b54c4226d32be301`.

The available local archive is Windows x64 only. Windows ARM64, macOS Intel, macOS Apple Silicon, Linux x64, and iOS/AUv3 packages have not been produced. See [local build requirements](../docs/local-builds.md); the five desktop targets must be built on compatible local hosts and their archives can then be gathered for one release upload.
