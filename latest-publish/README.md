# Latest MagDrum packages

Download the current test builds from the [GitHub Releases page](https://github.com/MagnarHarestad/MagDrum/releases/latest).

Tagged prereleases publish these archives:

- `MagDrum-Windows-x64.zip` — standalone app, VST3 and PowerShell installer.
- `MagDrum-macOS.zip` — standalone app, VST3 and AU component.
- `MagDrum-Linux-x64.tar.gz` — standalone app and VST3.

Archives generated locally or by CI are ignored here; this directory is the in-repository package index. See [installing.md](../docs/installing.md) for host setup instructions.
