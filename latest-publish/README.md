# Latest MagDrum packages

Download the current Windows x64 test package from [MagDrum v0.1.1-test.30](https://github.com/MagnarHarestad/MagDrum/releases/tag/v0.1.1-test.30).

The current package is:

- `MagDrum-Windows-x64.zip` — standalone app, VST3 and PowerShell installer.

The package is intended for testing the VST3 instrument in Cubase Pro 15. Its installer defaults to the per-user VST3 location and preserves an existing MagDrum installation when replacing it. The standalone scanner lists programs exposed by drum instruments and lets users select them before saving kit state or scanning notes; VST3 instruments also support searching a user-selected folder for `.vstpreset` files and recalling compatible presets. Select a plugin-generated preview and use Open source kit to reload the instrument and its saved kit state. MIDI export and import preserve pattern length, including empty bars, and the step sequencer can render and play a sample-based audio preview with tempo changes and looping. The pattern editor can now set or remove tempo and time-signature events at any beat. Plugin scans can capture 1–8 repeats, store each take, and suggest velocity-layer and repeated-trigger variation candidates for listening review. Plugin note scans now run in a separate worker process so a plugin crash does not close MagDrum. The database keeps stable folder/plugin source records, backfills prior scan folders, and lets the browser filter by a specific folder source, measured duration, and spectral brightness. The browser now shows heuristic classification confidence and can isolate uncorrected Unknown or below-75% samples for review; the threshold is not calibrated. Manual category corrections update both generated previews and their linked plugin sounds. Structured JSONL logs record app lifecycle and scan outcomes under the user's application data folder. Missing or unreadable samples now produce a clear preview error and a structured warning log. SHA-256: `bbc710d328d9925213cefbfda843fa00a5e432fbddf95871c15b075157e61991`.

This package was built and tested locally on Windows x64; CTest passed (1/1). Publishing with GitHub CLI uploads the archive without starting Actions runners. Windows ARM64 requires Visual Studio's missing ARM64 C++ component; macOS Intel/Apple Silicon and AU packages must be built on a Mac with Xcode; Linux x64 can be built on Linux or in a configured WSL2 environment. Local build scripts, tested package details, and host requirements are documented in [local-builds.md](../docs/local-builds.md). The other four platform archives have not been produced yet.

Archives generated locally are ignored here; this directory is the in-repository package index.
