# Latest MagDrum packages

Download the current Windows x64 test package from [MagDrum v0.1.1-test.36](https://github.com/MagnarHarestad/MagDrum/releases/tag/v0.1.1-test.36).

The current package is:

- `MagDrum-Windows-x64.zip` — standalone app, VST3 and PowerShell installer.

The package is intended for testing the VST3 instrument in Cubase Pro 15. Its installer defaults to the per-user VST3 location and preserves an existing MagDrum installation when replacing it. The plugin test target loads a generated WAV, saves and restores plugin state, renders MIDI-triggered audio and checks velocity response. MIDI import reports ambiguous note assignments and lists competing semantic mappings; the pattern editor can compare note events, tempo/meter metadata and pattern length with the imported state. The sample classifier now avoids assigning a kick from low spectral centroid alone: it requires transient energy and avoids confident high pitches. The standalone scanner lists programs exposed by drum instruments and lets users select them before saving kit state or scanning notes; **Find standard presets** searches platform-defined vendor/plugin folders, with a separate custom-folder search. Select a preset result to ask that instrument to recall it. Select a plugin-generated preview and use Open source kit to reload the instrument and its saved kit state. MIDI export and import preserve pattern length, including empty bars, and the step sequencer can render and play a sample-based audio preview with tempo changes and looping. Plugin scans can capture 1–8 repeats, store each take, and suggest velocity-layer and repeated-trigger variation candidates for listening review. Plugin note scans now run in a separate worker process so a plugin crash does not close MagDrum; automated tests exercise its supervisor with an aborting child fixture. The database keeps stable folder/plugin source records, backfills prior scan folders, and lets the browser filter by a specific folder source, measured duration, and spectral brightness. The browser now shows heuristic classification confidence and can isolate uncorrected Unknown or below-75% samples for review; the threshold is not calibrated. Manual category corrections update both generated previews and their linked plugin sounds. Structured JSONL logs record app lifecycle and scan outcomes under the user's application data folder. Missing or unreadable samples now produce a clear preview error and a structured warning log. SHA-256: `cc45cc3a5c34aabb5909291e79350e1e58c091fb4dc9d7f84c99f545546fab02`.

This package was built and tested locally on Windows x64; both CTest targets passed (2/2). Publishing with GitHub CLI uploads the archive without starting Actions runners. Windows ARM64 requires Visual Studio's missing ARM64 C++ component; macOS Intel/Apple Silicon and AU packages must be built on a Mac with Xcode; Linux x64 can be built on Linux or in a configured WSL2 environment. Local build scripts, tested package details, and host requirements are documented in [local-builds.md](../docs/local-builds.md). The other four platform archives have not been produced yet.

Archives generated locally are ignored here; this directory is the in-repository package index.
