# Latest MagDrum packages

The local Windows x64 package is `MagDrum-Windows-x64.zip`. It contains the standalone app, VST3 instrument, and PowerShell installer for Cubase Pro 15 testing. It was published as [MagDrum v0.1.1-test.56](https://github.com/MagnarHarestad/MagDrum/releases/tag/v0.1.1-test.56), a locally built release that does not use GitHub Actions.

The desktop sample browser uses debounced background SQLite searches and fetches matching results in 250-sample pages, including text/tag, category, source/kit, feature, review, and sort filters. Sample scans persist each analyzed file immediately; plugin scans persist each completed capture so both can recover after interruption. Classifier-generated tags are stored separately from user tags, searchable, and shown in sample rows. Analysis version 4 reclassifies existing libraries once and preserves user tags and category corrections. Filename-based articulation labels are searchable heuristics, not waveform recognition. The plugin scanner offers offline-fast, realtime-paced, and system audio-device callback modes. It scans only the requested velocity levels. The VST3 sampler supports up to eight non-overlapping velocity layers per MIDI note. The installer warns about a pre-existing system-wide VST3 to help avoid duplicate Cubase entries. Both CTest suites passed (2/2), including a 50,000-row paging check, worker-crash recovery, an isolated end-to-end scan of the built VST3 with restored sample state and audible note-36 capture, realtime pacing, sample-rate metadata, virtual callback rendering, VST3 velocity-layer state checks, filename-boundary classifier checks, classifier-tag persistence/search/reclassification, and articulation-tag search. Third-party plugin behavior and the mobile preview's iOS runtime remain unverified. The local archive SHA-256 is `f6794b7960c59d70c5b43ccd1a5703def7c2e362be7543172c9a20aee9d0505f`.

The available local archive is Windows x64 only. Windows ARM64, macOS Intel, macOS Apple Silicon, Linux x64, and iOS/AUv3 packages have not been produced. See [local build requirements](../docs/local-builds.md).
