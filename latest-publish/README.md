# MagDrum local test packages

Release candidate [v0.1.1-test.142](https://github.com/MagnarHarestad/MagDrum/releases/tag/v0.1.1-test.142) contains Windows x64, Windows ARM64 and Linux x64. The Windows VST scan includes Cubase 15 Media folders; regression coverage verifies configured roots and duplicate removal. Translation catalogs now decode as UTF-8, fixing mojibake in accented Windows UI text. Windows plugin smoke coverage checks drum-machine, library and sort labels in all eight languages, including French accents. Windows x64 and Linux Release CTest suites passed (2/2 each). The Linux archive includes a per-user installer; its update test confirms previous bundles stay outside plug-in scan paths. The newly built Windows ARM64 app and VST3 identify as ARM64; native runtime testing remains outstanding. Linux CTest loads the release module through JUCE's VST3 host, scans MIDI notes 0–127 and verifies audible note 36 after restoring saved state. Ardour 8.4 recognizes the Linux package in Ubuntu 24.04 WSL2. An interactive Ardour session and physical Linux audio-device test remain outstanding.

The system-installed Windows VST3 remains .135. The .142 installer refuses replacement while Cubase15.exe PID 20148 is still running without a visible window. After that process exits, run the bundled `Install-MagDrum.ps1 -AllUsers` script as administrator. It installs into `C:\Program Files\Common Files\VST3\MagDrum.vst3` and moves the previous bundle to `%ProgramData%\MagDrum\VST3-backups`, outside Cubase's scan path. Restart Cubase and rescan its VST3 plug-ins to use the new build.
