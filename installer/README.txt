MagDrum VST3 for Windows (x64)

Close Cubase. Right-click Install-MagDrum.ps1 and choose Run with PowerShell,
or run it from an elevated PowerShell window. It installs the plugin to the
standard system VST3 folder: C:\Program Files\Common Files\VST3.

Then open Cubase 15, open Studio > VST Plug-in Manager and rescan plugins.
MagDrum responds to MIDI: C2 (MIDI note 36) is kick, D2 (38) is snare,
and other notes trigger the cymbal voice. Add it as an instrument and route
a MIDI track to it. This is an early test build with synthesized sounds.
