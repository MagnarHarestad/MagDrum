# Roadmap

1. **Library foundation:** standalone JUCE app, recursive WAV scan, SQLite index, filters, audition and cross-platform CI.
2. **Audio intelligence:** feature extraction, deterministic classification with confidence, similarity, tags and duplicate detection.
3. **Instrument scanning:** desktop VST3 discovery/hosting, manual kit selection, MIDI-note rendering and previews.
4. **MIDI compatibility:** semantic drum events, General MIDI/custom profiles, MIDI import/export and visible fallback handling.
5. **Platform products:** VST3 for Windows/macOS/Linux, AU for macOS, AUv3 for iOS/iPadOS where supported.
6. **Advanced analysis:** investigate model-assisted classification, articulations, velocity layers, synchronization and a step sequencer.

Desktop VST3 scanning is not an iOS requirement.
