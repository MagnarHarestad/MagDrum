# MagDrum Windows plug-in views

The Windows VST3 editor is organized into five views. Open MagDrum on an instrument track in Cubase and choose a view from the navigation row. The **Plugin Scanner** view can discover VST3 instruments, list exposed programs, import presets as kits, and run note capture from inside the VST. The separate instrument manager remains useful for plugin-specific editors.

## Sample Library

VST sample previews are decoded on a cancellable background worker, so large files do not block Cubase's editor thread. If you request another preview while one is loading, the older request is cancelled and the newer selection takes priority.

The sample map projects the indexed four-window, 16-band acoustic fingerprints onto two principal components so samples with similar spectra tend to appear near one another. Projection runs in a background worker. Libraries with more than 3,000 loaded samples show an even representative subset in the map while the full result list remains available. Points keep their drum-category colors. Hover to inspect a sample and click to select it; double-click a point to audition, and move the pointer away to stop that preview. Scroll the mouse wheel to zoom around the pointer and drag with the middle button to pan; points and their glow remain clipped to the map. Right-click a sample row for quick Assign to pad. Older samples without a usable fingerprint are placed using their duration and brightness instead.

Click **Stop** beside **Preview** to cancel a file decode or silence the current sample preview. The comparison window also has a **Stop** button below each waveform.

To audition a pair while comparing them, Ctrl-click exactly two sample rows and choose **Sample tools > Compare two selected waveforms**. Use the **Preview** button under either waveform to hear that sample through the instrument output; choosing the other button replaces the previous comparison preview.

In **Plugin Scanner**, **Scan plugin folders** checks the standard VST3 locations. Use **Choose VST3 folder** to include a user-selected directory. Discovery runs in the separate MagDrum helper, outside Cubase.

Library rows also show which MIDI notes and velocity ranges currently use each sample. This updates after pad assignment, clearing a pad, and project-state restoration.

On Windows, Native Access places its default content location at `C:\Users\Public\Documents`. MagDrum scans this shared root as well as detected vendor locations, so libraries installed directly beneath it are included. Nested known vendor folders are collapsed under the root to avoid scanning the same files twice.

Click **Scan installed libraries** to scan audio in detected default Native Instruments, Spectrasonics/STEAM and Steinberg/Cubase 15 VST Sound and Media folders, including Steinberg per-user content under Roaming AppData. The scan runs in the background across the folders it finds, can be cancelled during audio indexing and the follow-up drum-MIDI search, skips unchanged files, saves checkpoints, and resumes interrupted audio scans. It also searches those folders for drum-related `.mid` and `.midi` files; open **Drum MIDI (N)** in the sequencer to inspect and import a result. Use **Add sample folder** when your audio libraries are stored in custom locations. The audio index reads supported WAV, AIFF and FLAC files. The scan reports Steinberg `.vstsound` containers and Kontakt `.ncw` samples that it cannot read directly, then guides you to Plugin Scanner to capture audio from the installed instrument. The resulting sample index is shared with the MagDrum desktop app. VST sample searches and filter updates are debounced and run in the background, keeping the editor responsive with large libraries. In **Plugin Scanner**, click **Scan plugin folders** to discover VST3 instruments in the standard locations. Discovery runs in a separate MagDrum process so third-party plugins are not loaded inside Cubase. Select an instrument and click **Scan programs** to list programs it exposes, or choose **Choose VST3 preset** to select a `.vstpreset` file. Enter a kit name, then click **Import program as kit** or **Import preset as kit**. The helper loads the selected sound outside Cubase and saves its plugin state in the shared database. Select the saved kit, configure velocity levels and capture timing, then click **Scan kit notes**. That note scan also runs in a separate helper process; its captures and analysis appear in this VST's library. Select one of those captured samples and use **Sample tools > View layer candidates** or **View round-robin candidates** to review the analysis and save confirmed velocity ranges or take groups. The separate **Plugin instruments** manager remains available for instrument-specific editor interaction. Captured instrument samples show their source plugin, kit, MIDI note, velocity, articulation and take in the browser. Search by text/tags or filter by category, source, kit, duration, brightness and review confidence. Choose a sort order, then use **More samples** to page through large libraries. The list shows category, duration and measured brightness; the map projects stored acoustic fingerprints onto two principal components so sounds with similar spectra tend to appear near each other, with dots colored by category. Samples without a fingerprint use duration and brightness for an estimated position. Hover a point for its filename, category, duration and brightness; click it to select the sample. Click a point or list row to select a sound, then use **Preview** (or double-click a list row) to audition it. Select a pad in **Drum Machine** first, return to the library, and choose **Assign to pad** to load the selected sample on that MIDI note. **Sample tools** also provides category and tag editing, scan history, similarity and duplicate searches, waveform comparison, and portable metadata import/export.

## Drum Machine

The 4×4 pad grid follows the Boss DR-660 layout: crashes and ride sounds on the top row, toms next, side stick/clap/hi-hats on the third row, then Kick, Snare, Pedal HH and Cowbell along the bottom. The Windows x64 build uses Cubase's octave convention for pitch labels: bottom-left Kick is C1 (MIDI note 36), Snare is D1 (38), Closed HH is F#1 (42), Open HH is A#1 (46), Pedal HH is G#1 (44) and Cowbell is G#2 (56). Pads glow briefly when triggered. Click a pad to select it and audition its assigned sound. The panel beside the grid shows the sample waveform, file path and assigned velocity layers. **Load WAV** loads a local audio file directly; **Clear pad** removes all layers from that note. To assign a library sample, select the pad first, then return to **Sample Library** and use **Assign to pad**. Velocity ranges are inclusive, from 1 to 127, and may not overlap. The selected MIDI note has independent Gain, Pan and Tune controls plus an ADSR envelope (Attack, Decay, Sustain and Release) and low-pass Filter Cutoff. These values are applied during sample playback, saved in the Cubase project and restored with the pad.

## Sequencer

Choose a pattern length from 1 to 16 bars; the bar selector only shows bars within that length. The grid supports selectable 1/8, 1/16 or 1/32 grids, with up to 32 steps per bar and dedicated lanes for Kick (36), Snare (38), Closed Hat (42), Open Hat (46), Tom (43), Ride (51), Crash (49) and Clap (39). Each lane is permanently tied to its General MIDI note, preventing drum categories from being accidentally swapped. Right-click a step to set its velocity. Choose a time signature from the meter menu; the grid supports up to 32 steps per bar at the selected resolution and keeps the same MIDI-note mapping. Set tempo from 20 to 300 BPM. Use **Set event** and **Remove event** to edit tempo or time-signature metadata at any quarter-note beat; the event summary shows the metadata that will be exported. Tempo events also change the sequencer preview tempo. Time-signature changes on selected grid boundaries create the corresponding shorter or longer bar spans in the grid and remain in the exported MIDI. **Play** loops the selected pattern length through assigned samples. **Import MIDI** opens a file picker; **Drum MIDI (N)** lists patterns discovered by the library scan. Imports use the selected profile and report unmapped, ambiguous and out-of-range notes. MIDI import selects a pattern length from the file duration, up to 16 bars. Length, meter, pattern steps and metadata are saved with Cubase plug-in state; shortening the pattern is rejected if it would hide existing hits. **Export MIDI** writes only the selected pattern length, including step velocities and all stored tempo/time-signature events. Steps with no sample assigned remain silent during preview and will play if Cubase receives MIDI for a loaded note.

## MIDI Maps

Choose General MIDI or a saved profile, edit drum/articulation-to-note mappings, and import or export profiles as CSV. Saved profiles are stored in the shared MagDrum sample database and the selected profile is also stored with the Cubase plug-in state. The current sequencer pattern, tempo, length, meter and edited MIDI metadata are stored with that state too. Profiles apply to MIDI file import/export; the drum-machine pads and incoming Cubase MIDI remain on their named General MIDI notes so assigning a sample to a pad does not change its playing note.

## Install and rescan

For a per-user install, double-click `Install-MagDrum-User.cmd`. It writes to `%LOCALAPPDATA%\Programs\Common\VST3` without elevation and backs up the previous user copy under `%LOCALAPPDATA%\MagDrum\VST3-backups`. VST3 hosts prioritize that user path over the global Program Files path. If an old system-wide MagDrum copy exists, the installer can request one UAC approval to move it and other old MagDrum bundles to `%ProgramData%\MagDrum\VST3-backups`; after that migration, per-user updates run without UAC. The no-UAC path requires the bundled Visual C++ runtime to already be installed. For a system-wide install or replacement at `C:\Program Files\Common Files\VST3\MagDrum.vst3`, use `Install-MagDrum.cmd` and approve standard Windows UAC. Start Cubase and choose **Studio > VST Plug-in Manager > Rescan All**.

## Instrument discovery progress and recovery

Choose **Plugin Scanner** to search for VST3 instruments. The status area shows the discovered instrument candidates and scan percentage. MagDrum caches plugin descriptions and skips unchanged modules on later refreshes; effect-only bundles are excluded whenever their VST3 manifest or cached description identifies them as effects. Discovery runs in the bundled helper, outside Cubase. The helper saves each completed module and JUCE records any module that crashes; MagDrum automatically restarts the helper to continue with the remaining plugins. A failing third-party plugin therefore cannot close Cubase or erase already discovered instruments.
