BUILT AROUND DRUM SOUNDS

Find it, hear it, map it.

01 · LIBRARY

Search your sample folders

Scan WAV, AIFF and FLAC files into a local SQLite index. Filter by filename, folder, category or your own tags, then audition without changing the source files.

02 · INSTRUMENTS

Capture plugin kits

Load an installed instrument, choose a kit, save its state and render MIDI notes at selected velocities. Previews and scan metadata join the same library.

03 · MIDI

Carry a pattern between kits

Edit and save General MIDI or custom drum maps. Import and export Standard MIDI files, with tempo and time-signature events retained.
