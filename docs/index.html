MADE FOR THE WAY DRUMMERS WORK

A library that understands drums.

01

One sound browser

Index WAV libraries and later, sounds captured from supported drum instruments. Filter by name, type, kit and source.

02

Hear before you choose

Audition samples quickly, compare sounds and keep original library files untouched.

03

Patterns that travel

Map MIDI notes to semantic drum events, then translate for another kit with clear handling when an articulation is missing.
