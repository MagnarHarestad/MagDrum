BUILT AROUND DRUM SOUNDS

Find it, hear it, map it.

01 · LIBRARY

Search your sample folders

Scan WAV, AIFF and FLAC files into a local SQLite index. Filter, audition, inspect waveforms and compare likely near-duplicate candidates without changing the source files.

02 · INSTRUMENTS

Capture plugin kits

Load an installed instrument, choose a kit, save its state and render MIDI notes at selected velocities. Previews and scan metadata join the same library, with timbral layer-change candidates to review.

03 · MIDI

Carry a pattern between kits

Edit drum events, preview an eight-lane pattern with indexed sounds, and save General MIDI or custom maps. Import/export CSV mapping profiles and Standard MIDI files, and edit tempo and time-signature changes at any beat.
