# Licensing status

The MagDrum project license has not been selected. The specification says this
decision must be made before distribution, so the repository intentionally does
not include a project `LICENSE` file yet.

MagDrum pins JUCE 8.0.12 in `CMakeLists.txt`. JUCE 8 is dual-licensed under the
GNU AGPLv3 and a commercial JUCE license. The chosen JUCE licensing path needs
to be compatible with how MagDrum source and binaries will be distributed. A
commercial JUCE license may be required if MagDrum will be distributed under a
proprietary license. Review the [JUCE 8 license terms](https://github.com/juce-framework/JUCE/blob/8.0.12/LICENSE.md)
and the [JUCE 8 EULA](https://juce.com/legal/juce-8-licence/) before deciding.

This note is a project status record, not legal advice. Once the project owner
chooses a license, add the corresponding project license and a third-party
notices/SBOM file before stable distribution.
